# Moving beyond .fit() and .predict()

In the modern landscape, being a Data Scientist is no longer just about cleaning CSVs and calling .fit() and .predict(). To deliver real value, DS-people should transition into an AI Engineer. AI Engineer is a modern paradigm, representing someone who can build, deploy, and scale robust machine learning systems. To put is short, a person who can desing and implement everything when it comes to data and machine learning.

This repository is created for my studying purposes. Here we focus on mastering the "Engineering" in AI Engineering. We move beyond the model and focus on asynchronous programming, containerization, scalable API design, and MLOps best practices.
